# Examples

## dental-saas-gcc

A real, unedited run of the Claude Code skill in standard mode (6 directorate subagents, about 10 minutes, WEB MODE OFF).

Idea given:

> Launch a B2B appointment scheduling SaaS for independent dental clinics in the UAE and Saudi Arabia. Goal: 300 paying clinics in 12 months. Budget: 250,000 USD seed. Team: 2 engineers, 1 founder doing sales. Price idea: 79 USD per clinic per month.

Result: **Low viability as submitted, Medium if restructured.** The audit evaluated all 5 mandatory cross-checks, found 4 more on its own, and reconciled 7 live conflicts.

Start with [`blueprint.md`](dental-saas-gcc/blueprint.md). Trace any `[A##]` tag to `agents/agent_##.md`.

Every market figure in this run is ASSUMED (no web access). It shows how the system reasons. It is not market research.
